## 3. NEW CORE ARCHITECTURE

Implement a hybrid system:

**ORIGINAL IMAGE → MAGIC LAYERS → SEMANTIC AUDIT → SELECTIVE NATIVE REPAIR → CANVA QA → BUYER TEST.**

Existing Python reconstruction remains an optional repair engine and fallback.

### A. Canva Magic Layers

Magic Layers is the preferred first-pass decomposition for suitable flat designs, especially vector-oriented posters.

Use the official Canva image-to-design import capability where authorized and available.

Official documentation:

https://www.canva.dev/docs/apps/rest-apis/reference/design-imports/create-image-to-design-import-job/

API:

`POST /rest/v1/image-to-design-imports`

It accepts the `asset_id` of an image already uploaded to Canva and produces a **new editable Canva design** asynchronously.

Required authorization includes `design:content:write` and the user's `image_to_design_imports` capability.

**IMPORTANT:**

- The API is preview and may change.
- It consumes Canva AI credits.
- Check quota, eligibility, and authorization first.
- Do not initiate chargeable jobs without explicit user approval.
- Do not process the full batch automatically.
- Do not claim the API accepts custom scene JSON or instructions for individual output layers.
- Do not invent a Magic Layers prompt API if none is documented.

If the REST API isn't accessible in the current account or environment, support the officially available Canva Magic Layers UI workflow and import its resulting design for subsequent inspection.

### B. Semantic inspection

Treat Magic Layers as an initial candidate, not an infallible solution.

Inspect its resulting Canva design:

- Native text objects.
- Native shapes and paths.
- Raster image layers.
- Background modules.
- Bounding boxes.
- Z-order.
- Typography and wording.
- Color properties.
- Occlusion artifacts.

Use official supported SDK/API read operations where available.

If the API cannot expose an element property, use an explicit manual QA gate rather than guessing.

### C. Reconstruction repair

Match the Magic Layers output to the source image and existing `manifest.json`.

Identify:

- Incorrect text.
- Missing objects.
- Raster graphics that should be native.
- Duplicated graphics.
- Damaged backgrounds.
- Lost gradients.
- Incorrect path geometry.
- Mismatched fonts.
- Z-order errors.

Repair **only failing elements** using the existing Python pipeline or Canva Apps SDK.

Do not delete successful Magic Layers elements merely to recreate them.

## 4. BRAND-ADAPTIVE POLICIES

Determine reconstruction strategy per semantic element.

### KINRAVA — PHOTO PRESERVE

Goal: preserve photographic integrity while allowing meaningful text and graphic editing.

- Keep original humans, equipment, gym lighting, and photographic details intact.
- Do not remove entire athletes to manufacture a clean gym background.
- Do not run broad LaMa inpainting on human regions.
- Prefer a faithful photo module with separately editable typography and simple geometric accents.
- Use Magic Layers only when the design and image regions are suitable.
- If a native stripe would expose baked-in graphics, flag this limitation.
- Never conceal damaged backgrounds with blur.
- Native text must retain correct wording and typography.

**Visual preservation takes precedence over unnecessary photo-layer separation.**

### VECTALLY — VECTOR FIRST

Goal: fully editable native Canva illustrations and typography.

This is the primary target for Magic Layers integration.

- Treat icons, charts, financial documents, connectors, ribbons, boxes, and decorative shapes as semantic vector objects.
- Inspect whether Magic Layers produced actual editable shapes or merely independently movable raster images.
- Reconstruct remaining rasterized primary illustrations using native Canva paths where feasible.
- Group related components meaningfully.
- Preserve independently editable fill colors.
- Verify every text string against the original.
- Use brand-aware font mapping.
- Avoid flattening gradients silently.
- Reject `FULLY_EDITABLE` status if primary vector illustrations remain rasterized.

The target is not maximum layer count; it is **meaningful native editability**.

### DORVAN — RENDER PRESERVE

Goal: retain automotive and glossy render detail.

- Preserve cars, material texture, reflections, specular highlights, and realistic lighting as raster hero modules.
- Do not aggressively trace glossy details into polygon fragments.
- Reconstruct native text and geometric accents separately.
- Support controlled recolor where technically feasible.
- Differentiate:
  - Native shape recoloring.
  - Canva image color effects.
  - External raster recoloring.
- For selective raster recolor, preserve luminance and protect neutral highlights and unrelated regions.
- Provide alternative tested raster color variants if independent buyer recoloring is not feasible.
- Do not advertise a feature that requires an unpublished developer app as universally accessible to template buyers.

## 8. QUALITY ASSURANCE

Implement three separate QA verdicts.

### PASS-STRUCTURE

- Correct native element types.
- Correct object relationships.
- No duplicates.
- Correct z-order and position.
- No critical missing elements.

### PASS-FIDELITY

Compare source PNG against actual Canva export.

Measure:

- Global and regional SSIM.
- MAE / color difference.
- Edge alignment.
- Text accuracy.
- Protected image-region preservation.
- Missing or duplicated design objects.

Use aligned, same-size images.

Do not accept visually catastrophic results based on a high overall metric alone.

### PASS-BUYER

Perform meaningful editing tests:

- Change headline.
- Change accent color.
- Edit illustrative vectors.
- Replace photo module where promised.
- Export again.
- Verify layout integrity.
- Confirm buyer access to the advertised editing features.

Every result must be `PASS`, `FAIL`, or `NOT_TESTED` with evidence.

**Successful Magic Layers conversion is NOT equivalent to buyer-test PASS.**
