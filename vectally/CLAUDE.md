**Petunjuk repository VECTALLY**

Baca README_CLOUD.md, kemudian handoff/REPORT_VECTALLY.md dan handoff/STATE.json.

Sumber84 gambar ada di sources/VECTALLY. Jalankan python3 handoff/cloud_audit.py sebelum mengubah resep.

File handoff asli berasal dari Windows. Port path sumber/runtime ke repo cloud sebelum rebuild. Jangan mengasumsikan drive C:/D:, Windows fonts, node_modules, PowerShell atau sesi Canva/CUSBE asal tersedia.

Nama paket atau skor mask tidak membuktikan sumber1:1. Jangan mengubah copy menjadi vector statis atau menonaktifkan validasi font. Asap heavy pada S06 adalah blocker yang diketahui.

Otomatiskan langkah deterministik melalui script; gunakan penilaian semantic dan visual untuk keputusan yang tidak dapat dibuktikan oleh validator.
